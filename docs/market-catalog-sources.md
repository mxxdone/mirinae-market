# 시장 후보와 지역 기준자료

시장 후보는 등록 입력을 돕는 최초 스냅샷이다. 후보가 존재한다고 판매점이 등록되거나 구매자에게 노출되는 것은 아니다. 관리자 확인 후 별도의 시장 ID로 등록한다. 정기 동기화와 기존 등록값의 자동 덮어쓰기는 제공하지 않는다.

## 출처

- 시장: 소상공인시장진흥공단 [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do), 데이터 기준일 2025-11-10, 1,393건. 포털의 공식 JSON 다운로드가 사용하는 `/download/columList.json`과 `/download/standard.json`에서 전체 건수를 확인하고 다운로드했다. 원본에서 이름·도로명주소(없으면 지번주소)·좌표·기준일만 추출했다.
- 지역: 행정표준코드관리시스템 [법정동코드 전체자료](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010), 2026-10-16 다운로드. 현존 코드 중 시군구 수준의 269개 기준 행을 사용한다. 일반구가 있는 시의 상위 행은 기준표에 유지하되 선택 대상에서는 제외한다. 세종은 원본의 단일 시 코드를 사용한다.

## 변환과 확인

- 공식 코드 앞 5자리를 시군구 코드로, 앞 2자리를 시도 구분에 사용한다. 약칭은 명시적인 대응표이며 문자열의 접미사를 잘라 만들지 않는다.
- 시장 원문의 주소는 보존한다. 지역 코드 연결에만 강원도/강원특별자치도, 전라북도/전북특별자치도 및 원문의 ‘전북특별차치도’ 표기를 대응시켰다. 2026-07-01 전남광주통합특별시 변경은 [행정안전부 안내](https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=126845)와 현재 지역 원본에 따라 지역 연결에 적용한다. 새 지역의 약칭을 임의 생성하지 않고 정식 명칭을 표시한다.
- 정확한 지역을 연결할 수 없는 후보 45건은 지역 미확인 상태로 보존한다. 유효 좌표가 없는 16건도 값을 임의 생성하지 않는다. 관리자가 필수 정보를 확인·보완하기 전에는 시장으로 등록할 수 없다.
- 후보 ID는 원문 시장명과 대표 주소의 SHA-256이다. 같은 자료의 재실행으로 후보가 중복되지 않도록 Flyway 버전 마이그레이션으로 한 번 적용한다. 후보 변경은 실제 시장의 관리자 수정과 구분한다.
- 원본 주소·좌표는 등록의 정확성을 보장하지 않는다. 관리자가 확인하며 지도상 표시 위치를 조정하더라도 대표 주소를 자동 변경하지 않는다.

원본 해시·행 수와 지역 미확인 목록은 로컬 검증 증거 `market-catalog-manifest.json`에 둔다. 런타임은 외부 자료 다운로드에 의존하지 않으며 최초 적재 SQL은 V9에 고정한다. 기존 시장·매장·주문은 V8에서 ID를 유지하고 위치 미등록 상태로 보존한다.
