개인정보처리방침 (검토용)

작성일: 2026-11-14

검토용 문서입니다. 운영자·문의처와 일부 기록의 보관기간은 아직 확정되지 않았습니다. 공개 운영 전 보완이 필요하며 시행일은 미정입니다.

1. 회원가입과 로그인

  • 일반 가입에서는 로그인 아이디, 표시 이름, 이메일, 비밀번호를 처리합니다. 비밀번호는 원문 대신 단방향 해시로 저장합니다.
  • 소셜 가입에서는 카카오·구글의 제공자 종류와 사용자 식별자, 동의 범위에서 전달된 표시 이름·이메일·이메일 확인 상태를 처리합니다. 로그인 수단을 구분하고 가입 정보를 채우거나 계정 연결을 확인하는 데 사용합니다.
  • 이메일은 중복 가입과 기존 계정 연결 후보 확인에 사용합니다. 이메일이 같다는 이유만으로 계정을 자동 연결하지 않습니다. 이메일 소유 확인·이메일 변경·계정 복구 기능은 현재 제공하지 않습니다.

소셜 로그인은 선택한 제공자의 인증 페이지에서 진행되며, 제공자의 비밀번호를 미리내 마켓 가입 폼에 입력하지 않습니다.

2. 기능 이용 중 처리하는 정보

기능 사용에 따라 장바구니, 모의 주문·결제·환불·수령 기록, 리뷰와 제보 내용을 처리합니다. 판매자 계정의 등록·관리에는 담당자 이름과 연락처도 사용합니다. 공개 리뷰에는 본인이나 타인의 개인정보를 입력하지 마세요.

‘내 주변’을 선택하고 브라우저 위치 권한을 허용하면 현재 좌표를 받아 주변 시장 검색 요청에 사용하고 지도에 위치를 표시합니다. 위치 권한을 거부해도 지역·시장명으로 검색할 수 있습니다. 지도 표시에는 네이버 지도 서비스를 사용합니다.

3. 로그인 유지와 보안

로그인 유지와 요청 위조 방지를 위해 쿠키와 인증 상태를 사용합니다. 브라우저의 쿠키 차단·삭제 설정에 따라 로그인 유지 등 일부 기능이 제한될 수 있습니다.

4. 보관과 탈퇴 시 처리

가입 정보는 계정 유지에 사용합니다. 구매자 탈퇴가 완료되면 표시 이름을 ‘탈퇴회원’으로 바꾸고 원래 이메일과 비밀번호 해시를 복원할 수 없는 값으로 대체합니다. 계정 연락처와 장바구니를 정리하고 서비스 내 소셜 연결을 제거하며 기존 인증을 무효화합니다.

내부 계정 식별자, 로그인 아이디 예약, 과거 모의 주문·결제·환불·수령 기록과 리뷰·제보는 남습니다. 로그인 아이디 예약은 과거 기록이 다른 회원에게 연결되는 것을 방지하기 위한 것입니다. 이 처리는 모든 기록의 삭제나 완전한 익명화를 뜻하지 않습니다.

남는 기록과 백업·로그의 구체적인 보관기간 및 파기 절차는 확정 전입니다. 모의 거래 기록에 법정 거래기록 보존기간이나 자동 삭제를 일괄 적용하지 않습니다.

5. 내 정보 확인과 문의

구매자는 로그인 후 ‘내 계정’에서 계정 정보를 확인하고 표시 이름을 수정하거나 탈퇴할 수 있습니다. 이는 별도의 개인정보 열람·정정·삭제·처리정지 요청 창구를 대신하지 않으며, 요청 접수 방법은 문의처 확정과 함께 보완할 예정입니다.
